# Public assets

- [`site.webmanifest`](site.webmanifest) makes the app installable.
- [`sw.js`](sw.js) caches the shell and assets for offline use.
- [`favicon.svg`](favicon.svg), [`icon-192.png`](icon-192.png), and [`icon-512.png`](icon-512.png) provide app icons.

See the [project README](../README.md) for installation behavior.
