# Source

- [`timer.ts`](timer.ts) contains timing and cycle rules.
- [`index.tsx`](index.tsx) renders the timer and keeps its state in local storage.
- [`locale.ts`](locale.ts) contains English, Portuguese, and Spanish UI text.
- [`locale-preference.ts`](locale-preference.ts) reads and writes the shared PLUNZ language preference.
- [`style.css`](style.css) contains the mobile-first layout.

See the [project README](../README.md) for setup and behavior.
